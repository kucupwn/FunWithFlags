# Fun with Flags

A simple game where you guess countries and official territories by their flags.

Once you've guessed the country or territory, you have to pick its capital from four possible answers.

## Controls

- **Right Arrow** → Next country
- **Enter** → Submit answer
- **1 / 2 / 3 / 4** → Select the corresponding capital
- **F2** → Reveal the answer

## Good to Know

- Fuzzy matching is enabled for country and territory names (a 60% match is enough).
- For multi-word names, matching just one word is enough, excluding "and", "of", and "the".
- If you fail to guess the capital, the country will appear again, and you'll have to guess the country name again too.
- Skipped countries will appear again later.
- Revealing the answer only shows the country or territory name. You'll have a 25% chance of guessing the capital correctly anyway.
- Once the game starts, you don't need the mouse — the input field stays focused.
